## Remaining practical limits

R04 remains a coverage boundary, not a failed observed core workflow: conservative PDF/DOCX contracts and explicit human transcription do not support arbitrary commercial layouts automatically. Actual browser testing covered generated DOCX, PDF and CSV; the suite covers more supported/unsupported formats. This is not independent real-document accuracy research.

No exhaustive power-loss matrix, thousands of billable calls, histories near the 1,000-journal cap, multi-user/cloud use or external security audit was performed. Existing lock/journal fences remain intentionally conservative. A failed staged recovery may leave an invisible `.pending-*` diagnostic directory; it is never listed as a recovered success and is not automatically deleted. Legacy journal identities absent from saved data cannot be reconstructed reliably. Unsaved drafts live in session memory, not durable crash recovery.

No blocking P0/P1 or remaining R01–R03 functional defect was observed in the exercised lifecycle. This is a bounded finding; the owner gate is still one independent acceptance, not a prerequisite delegated back to the owner for engineering completion. Full visual redesign remains reserved.

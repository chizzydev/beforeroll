## Human documentary review and continuity

**Evidence → Documentary scope** opens the scene-specific review before document-level roles and relationships. Confirm the scene, document and exact passage beside its original quotation. Interpretation starts unselected. Select it yourself, give a rationale and affirm that you checked the original before saving. Changing source or scene clears the interpretation and affirmation; the visible quotation and URL must match your selectors. A source-context mismatch blocks saving. Notes retained in a draft are not a decision.

One stored document cannot amend itself. A mixed-content source such as U01 uses passage-level review; document relationships require two distinct documents and an explicit relationship choice. **Supporting evidence needed** may mean an issued supporting instrument is missing even when the imported original is present. Historical `NEEDS_SOURCE` records keep their original decision codes.

Refresh and Back/Forward retain production, scene, document and passage identity. **Return to scene** preserves investigation context. A missing production opens an explained chooser rather than silently selecting unrelated data. The chooser distinguishes same-name copies by ID and recovered space. Keep sensitive source text, API keys and tokens out of shared URLs.

## Private backup and separate-copy recovery

In authenticated owner mode, use **Evidence → Exports & recovery** to create an encrypted backup with your own passphrase. Keep it securely. Verify the backup before restoring; a wrong passphrase or damaged envelope must not produce a restored production. Restore into a separate copy using the required exact production ID. Its independent local version starts at 1; that does not rewrite the snapshot's source/review history. Confirm original custody and journals, inspect the recovered scenes and review records, then refresh. **Lock workspace** ends the owner session; unlocking restores the selected route. Commit or explicitly remove staged review work before locking. Evaluation intentionally does not offer private recovery.

## Owner-mode fresh documents

The existing private launcher/authentication remains. Import originals and the scene register, compare their text, then use **Work → Source checks → Discover documentary review tasks**. Select whole documents/scenes, choose whether to include Fill investigations, confirm source identity and preview all requests/cost reserve. No clause selection or custom extraction question is required.

Only an explicit current preview, local operator token and billing affirmation can start a new scope. The API key stays on the server. A missing/uncertain response or cost stops further dispatch; never remove a consumed journal/lock to retry. The completed Batch B and previous campaigns are closed and must not be rerun. A future live case needs its own scope and authorization/budget.

A source claim of issue is not actual issue/authenticity. A reference is not necessarily a requirement or proof of corpus-wide absence. Supporting evidence, activity applicability, personnel/protection readiness and permission remain human work. The app is useful for organizing investigation, not granting filming clearance.

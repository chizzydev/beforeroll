## Reproduce interactively

Run `node scripts/release/evaluate.mjs` from the repository root and open the printed localhost URL. On Windows, `Start-BeforeRoll-Evaluation.cmd` is also available.

1. Overview → **Investigate scene** S31.
2. Open **Why this task exists** and **Read original & provenance** on lender work.
3. Inspect the claimed variation / **Consent Schedule CS-9** investigation.
4. Switch to S32 and compare the case-only plan and unissued extension.
5. Inspect the disclosed Fill scope disagreement in the source investigation.
6. Record an explicitly fictional **suggestion review**. Inspect Work and Evidence → History.
7. Evidence → **Exports & recovery** → download Markdown handover and JSON evidence.
8. Explore U01/U02; reset examples after confirmation. Stop the terminal with Ctrl+C or `stop`.

# Clocked core discovery — implementation design

27 October 2026. Written after source inspection and before implementation. No live calls authorized for this engineering run.

The existing `planIntelligence` already inventories every scene × permit unit, verifies Unicode spans and transcription gates, and builds the exercised two-noul Decide request. Its frozen bytes will remain unchanged. The old durable execution schema accepts only Decide answers and does not retain full HTTP bytes. The accepted literal decoder validates the three-field Extract responses but the current coordinator projector deliberately routes only the recorded U01 experiment. These are real capabilities, not absent features.

## Increment

An owner-only discovery preview selects documents and scenes, never clauses. It filters the complete existing plan to that explicit scope, inventories every pair, and reserves an Extract for every distinct unit (upper bound). It also requires a current human source-identity acknowledgement tied to normalized hash, revision, original import receipt and source epoch. That acknowledgement is not documentary authentication. PDF transcription review remains mandatory.

A separate versioned discovery journal is necessary because the old fixed Decide checkpoint cannot store Extract receipts or exact HTTP bytes. It shares the existing per-production execution lock and process-wide model allowance, leaves old journals untouched, and is archived in lifecycle backups. One source-scope fingerprint has one execution fence. Intent is fsynced before dispatch, all original request and returned response bytes are retained, and interrupted requests remain permanently uncertain. No request retry or automatic run continuation. Explicit bounded owner authorization is required; preview alone makes no request. Stops, invalid responses, revisions, quota, unknown reported cost and provider failures retain partial evidence and all unassessed pairs.

Decide is a relevance router only. Links at or above the existing conservative 0.8 threshold may trigger the exact accepted uniform three-field Extract request, once per unit shared across scenes. Low and ambiguous links remain visible. Every returned fact passes the existing strict source decoder. Exact named-other-scene and narrative/proposal cues conservatively quarantine suggestions; these lexical fences are incomplete safety checks, not an alternative semantic classifier. Unknown applicability, issuance, authenticity and fulfillment remain human questions even for accepted suggestions. Empty Extract never removes the underlying documentary review.

Projection revalidates current source/scene hashes and epochs, raw receipts and request definitions before deriving candidates. It joins the existing coordinator projection inside the atomic dossier, scene workbench, human suggestion-review log and exports. Source changes retire candidates; reversals cannot reactivate old epochs. Historical job identities and coverage remain available. Model output never writes authority, fulfillment, scene clearance or source-review decisions.

The existing Analysis stage receives only the functional controls needed to preview/authorize/stop/read/export this job. No layout redesign or BR work. Evaluation shows its historical U01 replay and explicitly states that generalized discovery has no recorded whole-run replay yet; live discovery is disabled, even with ambient credentials.

## Cost and evidence limits

Concurrency is one. A preview includes maximum Decide/Extract/total calls and a bounded owner-declared credit reserve per request. This reserve is not a provider quote: the service does not provide an enforceable pre-dispatch credit ceiling. Unknown cost or a returned charge above reserve halts further dispatch; a single provider charge can exceed the reserve. The owner must accept that limitation. All HTTP failures may be billable. No local cap is represented as a guarantee about provider billing.

Controlled transports establish engineering behavior only. The same-document AI-off comparison enumerates original deterministic findings and zero model-derived tasks; the Clocked branch reports only tasks caused by accepted responses, source-pair coverage, latency and returned credits. Neither workload savings nor generalized discovery reliability is established. A separately authorized independent fresh-document owner run remains mandatory.

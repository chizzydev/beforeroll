27 October 2026. **Implementation candidate; final owner acceptance pending.**

BeforeRoll connects planned scene activity to the original permit language and the human work that follows. Documentary text, Clocked interpretations and human reviews are separate evidence classes. No view establishes filming clearance.

## Open the existing no-key Evaluation Mode

Double-click `Start-BeforeRoll-Evaluation.cmd`, or use the coordinated gate below. The browser opens a disposable fictional workspace automatically. It needs no Clocked key or owner token and makes no new provider requests. U01 loads its eight previously recorded Decide answers and the three matched, previously recorded Extract responses. U02 remains available through Example controls with its existing recorded replay.

Evaluation stores committed changes for the lifetime of that evaluation server. Refresh retains the current production, section, scene and selected source reading position. Back/Forward navigates those reading positions. Explicit reset discards fictional edits/reviews and restores the examples. Closing the evaluation server ends this disposable workspace; a later launch is a new evaluation. Uncommitted drafts are not represented as saved decisions; the existing leave-page warning still applies.

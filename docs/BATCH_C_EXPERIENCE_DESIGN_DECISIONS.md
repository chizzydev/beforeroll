## Three approaches

| Approach | Strength | Product evidence against / risk | Decision |
|---|---|---|---|
| Document-led reading room | Excellent documentary context, short paths to originals | Current source/scope page already buries the scene-specific decision below provenance/link forms. A judge must infer which scene matters; long repeated clauses dominate | Retain as Evidence, reject as principal journey |
| Investigation inbox | Fast triage across many scenes, compact review status and actionable rows | The current queue opens with repeated internal discovery titles and technical reasons. Leading with an inbox obscures the planned activity and can imply model tasks are exhaustive | Use grouped work and disclosure, reject as first experience |
| **Scene-led production brief** | Starts with planned activity and task differences; original source and human decision stay attached; existing four destinations remain familiar | Needs compact source-bound cards, purposeful opening and careful context restoration; must preserve negative/ambiguous checks and all audit detail | **Selected** |

Judgments are qualitative, not invented usability scores. The selected approach best serves first-view comprehension, visible Clocked contribution, task/source navigation and low implementation risk: it changes shared presenters/controllers, not intelligence contracts or stored evidence. Document-led detail remains reachable; the inbox remains a complete paginated register. Desktop uses a scene register and readable main column; narrow screens retain native scene selection and stack complete task/source/action groups. Keyboard and DOM order follow the same hierarchy.

## Shared hierarchy and safeguards

Overview: purpose → actual scene activities and counts → investigate. Scenes: activity → concrete prerequisite and documentary-investigation groups → exact original/provenance on demand → human review. Work uses the same cards plus the complete underlying source/operational queue. Evidence retains source custody, explicit human documentary scope, paginated History and version-bound handover/recovery.

The opening must derive counts and tasks from the real projection, never inject successful cards. A recorded origin is visible once per group; full source sentences, Unicode locators, raw model evidence, contracts and hashes remain available. Scope disagreement is visible before technical expansion. Acknowledgment remains separate from authority and fulfillment. Neutral documentary selectors require an explicit human choice and source-confirmation affirmation; self-links are unavailable and rejected by the existing server.

## Design references and boundaries

Read the existing external benchmark study and Editorial Intelligence Studio system; inspected baseline desktop/narrow screenshots. Preserve chalk/paper/rust/ink, Cambria/Segoe UI, rectangular reading surfaces, 44px controls, visible focus and reduced motion. Transfer principles, not artwork: anchored review (Frame.io), quiet grouped registers (Linear), complete edge states (Geist), scene vocabulary (StudioBinder). These are prior documented studies, not new live reviews of those services.

Owner local application sources are read-only references: DealForge's explicit candidate/trusted/human-authority separation, Decide's stable desktop/mobile navigation, and Skill Rooms' consistent shell and contextual action feedback. No unrelated application is modified, run or copied. Their visual identities and media are not imported.

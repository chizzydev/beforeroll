## Scientific question

## Baselines and leakage rules

AI-OFF is **the actual existing deterministic BeforeRoll review engine**: source row parsing, strict times, checks supported by trusted Extract fields, exact spans and review-state safeguards. It produces **no semantic clause relevance or documented-grant judgment**. Do not call this a contest against all possible deterministic NLP. The observed additional Clocked findings are an incremental capability, not proof of superior general accuracy. The gold is publicly supplied in the repo for reproducibility but is **never embedded in the model requests or used to drive the UI's classification**; the server sends only the candidate clause and current scene. U01/U02 are author-created synthetic examples rather than unbiased third-party cases.

## Fail-closed gates

A complete accepted experiment requires: correct fixture hashes; exactly 2 source-bound scenes; exactly 4 clause candidates per scene; original eight Clocked request SHA256 values reconstructed independently; valid typed Decide answers; per-scene source integrity; no silent partial success; source preview discloses omissions; and the *separate* five-band report with failures retained. Identity mismatch, partial result, invalid output, unscanned source, or non-authoritative request must **never** imply filming permission.

## Operational contract and evidence

The coordinator selects a production, complete documents and scenes, verifies source identity and authorizes a preview. Clause selection and question authoring are unnecessary. Every selected source unit is paired with every selected scene, with original hashes/revisions/epochs and exact Unicode ranges. All pairs survive into coverage, including ambiguous/negative/unassessed pairs. The full existing planner's 50,000-task integrity ceiling still applies before scope selection.

Decide uses the unchanged two-noul request: `activity_link` routes at ≥0.8, ≤0.2 remains a negative signal requiring source review, and intermediate values explicitly abstain. `granted_for_scene`, even 0.99 in adversarial tests, cannot create authority. A positive link may trigger one Extract per distinct unit, shared across selected scenes. The copied uniform three-field request is checked against the accepted recorded request in tests.

Literal facts must match original unit/full-document codepoint slices, UTF-8 bytes, hashes, fields/items and complete HTTP receipts. Distinct protective measures remain distinct; exact scene/document/epoch/field/span duplicates deduplicate. Tasks retain source quotation, containing unit, context-unit IDs, scene binding, Decide and Extract request/response hashes, model identity and provenance. Applicability, issuance, authenticity, supporting evidence and fulfillment remain explicitly unverified. Explicit other-scene/mixed-scene and historical/proposal cues quarantine suggestions into manual review. This is a conservative lexical safety fence, not proof of complete semantic classification.

The existing source reader, named suggestion-review log, scene workbench, Work surface, History and dossier consume that same derived candidate identity. A suggestion review cannot close original source questions, complete operational conditions or authenticate a permit. Any selected source/scene lineage change retires the selected discovery scope; A → B → A cannot revive its old epoch. Historical quotes/candidates remain in job history and exports. Unchanged sources outside that selected scope remain unaffected. Within a multi-source selected scope retirement is deliberately conservative rather than selective per pair.

The journal retains exact request bytes and returned body bytes, status, request/response/stored-body hashes, timestamps, latency, model identity, returned usage/timing (inside raw body), credit header and selected safe response headers. No credentials are stored as request headers. Broken streams retain received prefixes with an incomplete receipt. Oversized bodies are bounded and rejected. A credential echo is encrypted and rejected, never interpreted or exposed as plaintext. These are owner-held integrity records, not cryptographic provider attestation.

Each intent is fsynced before fetch; one scope has one permanent job fence. Concurrency one, 45-second request timeout, no HTTP retry, no resumed billable jobs. The legacy per-production execution lock and process allowance are shared. Uncertain overlapping request IDs remain fenced across scene-selection changes and the old execution route. A client also writes its one-shot intent before calling the application. Partial results cannot masquerade as completed journals, even with a recomputed outer checksum.

Local Windows readers briefly denied a journal replacement during early status-poll testing. The fix retries only that local rename, at most ten times; it never repeats fetch. The regression's real server/status path now passes. Invalid JSON/spans/categories, provider HTTP 422/429, unknown/excessive credits, cancellation, source changes, lost response, missing custody/configuration, stranded locks and recovery all leave explicit stopped/uncertain/unassessed evidence.

## Remaining limits and next decision

1. **Fresh live semantic acceptance remains pending.** The combined automatic Decide → Extract path has only controlled engineering validation here. No deployed-provider success is invented. A missed key obligation on the first independently chosen document must be recorded FAIL; no retroactive reference editing or automatic research loop.
2. The per-call reserve is not a provider quote/enforced credit cap. Unknown or excessive reported charges stop subsequent calls; a single charge can exceed reserve. Provider-side quota cannot be guaranteed by a local allowance. Missing model/schema/cost information halts safely.
3. Generalized relevance, scope, exclusion of historical/proposed passages and literal completeness are model-dependent and uncalibrated. Lexical quarantine can miss unfamiliar phrasing or suppress valid work. Every suggestion remains a human investigation candidate.
4. Scope-wide invalidation is conservative. Stopped scopes cannot resume. A different explicitly authorized scope may repeat known completed requests; the entire cost is reserved again. Unknown overlapping requests cannot repeat. Stranded locks require investigation, never deletion as a retry technique.
5. Legacy Decide-only completion counts remain separate from discovery counts, avoiding fabricated legacy results. New tasks are integrated in the dossier/Scene/Work/review/history/export loop, while original source reviews stay open.
6. Evaluation has no complete generalized discovery recording yet and says so. Historical U01 functionality remains accessible without credentials and sends zero fresh requests. No browser/GUI testing or BR refinement was undertaken in this increment.

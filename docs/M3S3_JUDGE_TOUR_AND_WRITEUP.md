## Sponsor value (truthful)
BeforeRoll uses **Clocked Extract** to parse the original familiar permit examples and **Clocked Decide** to compare unfamiliar scene activity prose with detected condition candidates and identify documentary grants. This is meaningful semantics distinct from deterministic clock arithmetic. The `noul` questions are scoped to single clauses, with no global legal permission claims. Four real owner-recorded M3-S2 calls are reusable for judges without credentials. The 25-point practical value, 30-point core API integration, 15-point additional endpoint integration, 20-point product and 10-point reproducibility components should each be evidenced rather than asserted. Category family Decide/Extract/Fill breadth is *not complete*; **Fill is not integrated** and adding it solely for endpoint count would weaken the claim.
